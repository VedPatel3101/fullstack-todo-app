# Full Stack Todo App 🚀

A Full Stack Todo List application built with React.js, Node.js, Express.js, and MongoDB to create, manage, update, and delete tasks.

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, JavaScript, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## ✨ Features

- Add new tasks
- View tasks
- Update tasks
- Delete tasks
- REST API integration
- Frontend and backend integration

## 📂 Project Structure

- `backend/` — Backend API and server
- `frontend/` — React frontend application

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/VedPatel3101/fullstack-todo-app.git
cd fullstack-todo-app
```

### 2. Start the backend

```bash
cd backend
npm install
npm run dev
```

Configure your required environment variables in a `backend/.env` file before starting the server.

### 3. Start the frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## 🔐 Environment Variables

Keep your `.env` file private. Never upload passwords, API keys, or database credentials to GitHub.
